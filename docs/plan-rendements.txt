0. PRINCIPE CIBLE (demande utilisateur 2026-11-16)
---------------------------------------------------
On ne mesure qu'une chose : le RENDEMENT d'une activité (unités par 6000
ticks de travail). Tout le reste en est DERIVE, jamais mesuré à part :

  XP / 6000 ticks   = Σ rendement(unité porteuse d'XP) × XP de l'unité
                      (XP de l'unité = dump du jeu / 10, source unique,
                      planner::method_way::action_xp)
  Profit / 6000     = Σ rendement(produit) × prix live
                      − Σ consommation(intrant) × prix live
                      (± temps de marché, voir §4)

Trois familles de rentabilité, toutes au prix du marché en direct :
  (a) farm      : récolter/combattre et vendre ce qu'on obtient ;
  (b) recette   : transformer des ressources (les siennes ou farmées) ;
  (c) 100 % market : acheter TOUS les intrants au marché, crafter,
                  revendre le produit fini au marché.

2. VISION : DES GUIDES GENERES, LUS PAR LES BOTS
------------------------------------------------
Inspiration (OSRS, pas 274 : idées seulement) :
  oldschool.runescape.wiki/w/Money_making_guide
  oldschool.runescape.wiki/w/Skill_training_guides
Les joueurs choisissent avec ces références. Nos guides sont la même
chose en plus générique et plus fourni : générés, jamais écrits à la
main, une ligne pour CHAQUE méthode jouable en F2P 274, recalculés quand
une mesure ou un prix change.

Guide money making (une ligne par méthode × site × outil × tranche) :
  famille (farm | recette | chaîne | 100 % market | flip), méthode fine,
  site, palier d'outil, tranche ; prérequis complets (niveaux, quêtes,
  outils, capital de départ d'un lot ; Wilderness = prérequis de combat,
  jamais un refus de zone) ; intrants/6000 (qté × prix courant) ;
  produits/6000 (qté × prix courant) ; profit/6000 ; XP/6000 par skill
  en bonus ; confiance (mesuré/estimé, n, âge, dispersion).
Guide d'entraînement (une ligne par skill × tranche × méthode × site ×
  outil × mode d'approvisionnement) :
  XP/6000, pièces/6000 (gain ou dépense), pièces/XP, ticks jusqu'à la
  fin de tranche, mode d'approvisionnement (autonome : intrants
  farmés, temps compté | marché : intrants achetés, pièces converties
  en temps, D17), prérequis, confiance.
Equilibre du marché, indirect : le guide lit le prix courant ; quand
trop de bots font la même chose, le prix du produit baisse (ZIP), la
ligne descend, le tirage pondéré répartit les bots ailleurs. Aucune
connaissance cachée (D22) : seuls prix publics et mesures publiées.

7. AUDIT DES SKILLS SANS PRODUIT (2026-11-16)
---------------------------------------------
Principe corrigé : "XP = rendement × XP de l'objet" ne couvre pas tout.
Règle générale : XP/6000 = Σ compteurs d'UNITES PORTEUSES × XP/unité,
une unité étant l'une des quatre :
  P produit réussi        (minerai, bûche, poisson, barre, objet forgé…)
  C intrant consommé      (bûche brûlée, os enterré, objet alché,
                           essence en runecraft, bijou enchanté)
  S lancer de sort        (téléport, malédictions, XP de base d'un sort
                           de combat, même raté)
  K dégâts / kills        (combat : XP = dégâts × 10 dixièmes × 4
                           selon le style, × multiplicateur du PNJ ;
                           PV = × 1,33 ; combat.rs2
                           give_combat_experience)

Skills F2P (274) :
  Attack/Strength/Defence  K, réparti selon le STYLE (accurate,
                           aggressive, defensive, controlled 1,33×3) :
                           le style fait partie de la clé de méthode.
  Hitpoints                K (1,33 par point), dérivé de tout combat.
  Ranged                   K (4, ou 2+2 Defence en longrange) ; flèches
                           = C au coût, jamais une unité d'XP.
  Magic                    combat : S (XP de base par lancer) + K (2 par
                           point) ; teleports/malédictions : S ; enchant,
                           bones to bananas, superheat, telegrab : P ;
                           alchemy : C (l'objet alché ; les pièces sont
                           le profit, pas l'unité).
  Prayer                   C (os enterré), souvent DANS un run de combat.
  Firemaking               C (bûche brûlée) ; les cendres tombent au sol
                           (firemaking.rs2:132), jamais ramassées : la
                           way "fire:* -> ashes" n'est pas l'unité.
  Runecraft                C (essence) : plusieurs runes par essence à
                           haut niveau, l'XP est par essence.
  Cooking                  P (réussi ; brûlé = 0 XP). Vin : XP à la
                           fermentation, différée, peut tomber après le
                           run.
  Crafting                 P par ETAGE (poterie : façonnage + cuisson,
                           deux XP pour un pot final).
  Smithing                 P (barre réussie ; fer 50 % d'échec ; forge
                           par barre) ; superheat = Magic + Smithing.
  Mining, Woodcutting,     P ; gemmes = sous-produit sans XP ; poissons
  Fishing                  multiples par méthode (XP par espèce).
  Quêtes                   XP forfaitaire (chains::QuestShortcut) : pas
                           un taux.
Activités sans XP (lait, eau, tonte, cueillette, moulin, teinture,
tannage, ramassage) : rendement seul, guide money making uniquement.

Constats live (rates-snapshot, store) :
  - firemaking : 424 rapports, bûches en "consumed", "rendements"
    parasites (Logs, Tinderbox, Fishing rod), XP attack/hitpoints
    parasites (combats pendant le run) ;
  - enchant_teleport : seuls les enchantements laissent une trace, les
    téléports ne produisent rien de mesurable aujourd'hui ;
  - telegrab_wine : 4 rapports, zéro flux ;
  - alchemy : intrants dont "Adamant pickaxe" (outil de la trousse
    permanente alché ? à vérifier, violation possible de la trousse) ;
  - combat : os ramassés puis enterrés dans le même run -> diff net = 0,
    l'XP de prière n'a pas d'unité visible.

Trous du système :
  T1 Le diff net efface tout ce qui est produit puis consommé dans le
     même run (os enterrés en combat, coupe + feu, fonte + forge, pot
     façonné puis cuit, poisson pêché puis cuit). Les unités doivent
     venir du ledger par action du SDK (item_ledger existe déjà,
     attribution "skill" dans la fenêtre d'XP) + compteurs d'événements
     (kills, dégâts, lancers), jamais du diff net.
  T2 Combat : kills seuls insuffisants pour la magie (XP de base par
     lancer) ; multiplicateur XP par PNJ à dumper ; style dans la clé.
  T3 Familles absentes du planificateur : teleport (3 sorts F2P,
     script enchant_teleport déjà capable), malédictions confuse/
     weaken/curse/bind (aucun script), bones_to_bananas (script, pas de
     famille), crumble_undead (exclu de best_combat_spell : nom absent
     du dump, alors que 24,5 XP de base au niveau 39).
  T4 action_xp est centré produit : firemaking -> ashes, alchemy ->
     coins ; il faut une table unité porteuse par famille.
  T5 XP différée (vin) : unité comptée à la fermentation.
Effet économique : ces skills sont les PUITS du marché (bûches, os,
runes de loi/corps/nature, objets alchés) : sans eux les objets ne
font que s'accumuler ; ils portent la demande qui équilibre les prix.
