P2-1 — Bot échoué : garde « aucune sortie » + coupe-circuit marché   [orchestrateur brain, market]   N1
  Cause : rien n'arrête un bot dont la position n'a de route vers aucune banque ; ses ordres continuent
  d'être appariés.
  Correctif (règle unique) : (a) avant chaque lancement, si le dernier rapport/échec est un NoRoute
  « Disconnected closest=<position du bot> » ou si le service nav ne trouve aucune banque depuis la
  position, le cerveau passe le compte en état typé `Stranded{pos}` : plus de lancement, une ligne
  error_events `stranded` (une fois), alerte dashboard, question à l'utilisateur (règle 7 ; récupération
  = D5) ; (b) marché : un compte `Stranded`, OU 3 deals d'affilée en timeout, met tous ses ordres en
  `dormant` (colonne existante) jusqu'à un deal réglé ou une levée explicite ; le moteur n'apparie pas
  un ordre dormant.
  Test rouge : (orchestrateur) rapport NoRoute Disconnected closest=position -> état Stranded, aucun
  launch au tick suivant ; (market) 3 timeouts d'un vendeur -> ses ordres dormants, aucun appariement.
  Vérification live : deals timeout < 5/h ; aucun compte > 50 NoRoute/h ; ligne `stranded` pour
  bellarhodes tant que N1-b n'est pas corrigé.
  Risque : faux positif sur un NoRoute ponctuel (exiger 2 positions identiques à 2 essais).

P2-2 — Collision : case d'appui d'une transition marchable et reliée   [gamedata/nav]   N1 (cause B)
  Hypothèse unique : la case d'appui (3032,3217,1) du gangplank de Port Sarim est marchable côté serveur
  (m47_50 jm2, pont du navire) mais bloquée dans notre collision statique (empreinte de la loc 2084 ou
  du bastingage) ; le pont (3032,3214-3216,1) est donc une composante sans sortie.
  Observation qui confirme : flags de collision serveur de (3032,3217,1) = marchable et (3032,3216,1)
  -> (3032,3217,1) sans mur ; infirme : la case est bloquée côté serveur aussi (alors l'arête doit être
  opérable depuis les cases adjacentes, comme toute loc).
  Correctif : balayage hors ligne de TOUTES les arêtes custom/ride : la case d'appui est marchable, ou
  l'arête est opérable depuis toute case d'où la loc est atteignable (portée d'interaction) ; aucune
  composante statique ne contient une case d'arrivée (`expect`/`to`) d'une arête sans autre sortie.
  Test rouge : golden nav « pont_port_sarim » : route (3032,3214,1) -> (3029,3217,0) trouvée ; test de
